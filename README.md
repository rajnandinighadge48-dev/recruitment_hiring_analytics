
# 📊 Recruitment & Hiring Analytics

> An end-to-end HR Analytics project focused on recruitment funnel performance, hiring source effectiveness, joining rates and department-wise hiring insights.

---

## 🎯 Project Overview

This project analyzes the recruitment and hiring process from candidate application to joining.

The objective is to transform recruitment data into meaningful HR insights that can support data-driven hiring decisions and improve recruitment effectiveness.

The analysis covers:

- Recruitment funnel performance
- Candidate conversion across hiring stages
- Recruitment source effectiveness
- Source-wise joining rates
- Department-wise hiring performance
- Time to hire
- Hiring cost
- Salary offered
- Overall recruitment efficiency

---

## 📌 Business Objectives

The project aims to answer key recruitment-related questions:

1. How many candidates move through each recruitment stage?
2. What percentage of candidates are shortlisted, selected and joined?
3. Which recruitment sources generate better joining outcomes?
4. Which departments have the highest number of hires?
5. Where are the major conversion gaps in the recruitment funnel?
6. How efficiently is the organization converting applicants into employees?
7. What recruitment insights can support better hiring decisions?

## 💡 Key Insights

### 🔹 Recruitment Funnel

- 60 candidates entered the recruitment pipeline.
- 49 candidates were shortlisted.
- 49 candidates progressed through the interview stage.
- 35 candidates were selected.
- 32 candidates successfully joined.

### 🔹 Recruitment Source Effectiveness

Employee Referral recorded the highest joining rate among the recruitment sources analyzed.

Source-wise joining rates:

| Recruitment Source | Joining Rate |
|---|---:|
| 👥 Employee Referral | 71.43% |
| 🎓 Campus Recruitment | 66.67% |
| 💼 Naukri | 60.00% |
| 🔗 LinkedIn | 52.94% |
| 📌 Indeed | 0.00% |

The results indicate that recruitment channels can perform differently in terms of candidate-to-employee conversion.

### 🔹 Department-wise Hiring

The analysis identified HR as the department with the highest number of joined candidates, followed by Sales, Finance, IT, Marketing and Operations.
